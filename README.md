# Rise of Fragrance in GenZ
What is driving the next generation of fragrance consumption? In this project, let's explore this.

[PT-BR]
O objetivo desse projeto é explorar e enriquecer minhas habilidades em consumer analytics and insights, estudando o comportamento da Gen Z no mercado de perfumaria nacional. 
A ideia é criar uma base sólida de dataset com trends, informações de consumo, em mercados estratégicos, e trazer uma análise estruturada, clara, e que demonstre o que é possível analisar no mercado.
